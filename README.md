## 3D Models

The current text and figure stay in place unless model URLs are configured. Put swappable GLTF/GLB files in `public/assets/models`, then set `REACT_APP_HERO_NAME_MODEL_URL=/assets/models/hero-name.glb` and/or `REACT_APP_ABOUT_MODEL_URL=/assets/models/about-figure.glb` before starting or building the app. Restart the dev server after changing these variables.

The hero and projects background files are grouped in `public/assets/backgrounds` for easy replacement. Adjust `--project-header-color` in `src/theme.css` to change the projects heading color.
